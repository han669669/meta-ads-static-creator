# Brand Context Capsule — Format Reference

> **What this is.** The structure `/brand` writes to
> `intelligence/brand-context.md` — a single, compact, **portable** page that
> concatenates the essentials of the whole brand into something you can paste
> into *any* AI tool (ChatGPT, Claude.ai, Gemini, a video tool, a copy tool)
> and instantly get on-brand output, without that tool having access to the rest
> of the brand folder. It is the "brand operating system in one page": the
> distilled export of `brand-strategy.md`, `counter-positioning.md`,
> `visual-guidelines.md`, `brand-voice.md`, `color-palette.json`,
> `typography.json`, and `products.json`.

Keep it to roughly **one page** (~400–600 words). It is a *summary*, not a
re-statement — pull only the load-bearing lines from each source file. Regenerate
it at the end of every `/brand` run (and whenever the brand context is updated) so
it always reflects the current state.

---

## Output structure

```
# [Brand Name] — Brand Context

*Portable brand context. Paste this at the top of any AI tool to get on-brand
output. Generated by /brand on [date] — the source of truth is the intelligence/
folder.*

## What we are
[2–3 sentences: category, what we sell, who it's for. From brand-strategy.md.]

## Positioning
- **Counter-position:** [the recommended one-liner from counter-positioning.md]
- **Value proposition:** [the brand-language version]
- **We stand against:** [the "stands against" line]

## Audience
[2 sentences: the person, psychographically — their frustration and what they
want. From brand-strategy.md.]

## Voice
- **Sounds like:** [the one-line voice from brand-voice.md]
- **Always:** [2–3 do's]
- **Never:** [2–3 don'ts / banned words]

## Look
- **Colours:** [Name #HEX — role, for each load-bearing colour from color-palette.json]
- **Type:** [Heading family / Body family, from typography.json]
- **Photography:** [one line — lighting + colour grade + mood, from visual-guidelines.md]
- **Prompt modifier (paste into image tools):**
  > [the full prompt-modifier paragraph from visual-guidelines.md, verbatim]

## Products
[A compact list — one line per product: Name — one-phrase description / key claim.
From products.json. Cap at ~10 hero products; note the total count.]

## Links
- Site: [url]
- [Any design-system / guidelines URL]
```

---

## Notes

- **Portable and self-contained.** Assume the reader/tool has *nothing else*. No
  references to other files by name, no "see X" — inline the actual values
  (hexes, font names, the prompt modifier, product lines).
- **Distil, don't dump.** If a source section is long, take its single best line.
  The whole value is that it fits in one paste.
- **Keep it current.** This file is a derived artifact — regenerate it whenever any
  source file changes (a new product, a corrected palette, a sharpened
  positioning). Stamp the date so the user knows how fresh it is.
- **Prompt modifier is the crown jewel.** Always include it verbatim — it's the
  single most useful thing to carry into an external image tool.
