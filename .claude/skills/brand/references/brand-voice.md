# Brand Voice — Format Reference

> **What this is.** The structure `/brand` writes to
> `intelligence/brand-voice.md`. Where `brand-strategy.md` captures *who* the
> brand is and `visual-guidelines.md` captures *how it looks*, this file captures
> **how the brand writes** — the load-bearing input for every skill that
> generates copy: `/meta-ads-static-creator` headlines, body copy
> and any on-image text. It is derived during `/brand` from
> the same research (site hero + product-page copy, About page, ad-library
> captions, founding story) and is fully editable.

Write clean markdown: `#` title, `##` sections, tight bullets, real examples.
Concrete beats abstract everywhere — quote the brand, don't describe it.

---

## Output structure

```
# [Brand Name] — Brand Voice

## Voice in one line
[A single sentence a copywriter could hold in their head: the brand sounds like
[X] — confident but not [Y], warm but not [Z]. Anchor it to a recognisable
register, not generic adjectives.]

## Tone attributes
- **[Attribute]** — [one line: what it means for this brand, with a tiny example]
- **[Attribute]** — [...]
- **[Attribute]** — [...]
  (3–5 total. Precise words: "dry-witted", "plain-spoken", "clinical",
  "hype-free" — not "friendly", "premium".)

## How it sounds — rules
- **Sentence rhythm:** [short and punchy / long and flowing / fragments for
  emphasis — describe the actual cadence, with a one-line example]
- **Person & address:** [first person "we" / second person "you" / imperative —
  how the brand talks to the reader]
- **Capitalisation & punctuation:** [sentence case / all-lowercase / Title Case
  headlines; em-dashes, exclamation policy, ellipses]
- **Emoji:** [never / sparingly / part of the voice — and which ones]
- **Claim style:** [how the brand makes claims — specific + evidenced / bold +
  minimal / playful + hyperbolic. Reference how it handles proof.]
- **Numbers, prices, offers:** [how it presents price and discounts — foregrounded
  or downplayed — matching visual-guidelines "Pricing and offers".]

## Vocabulary
- **Words the brand uses:** [signature terms, product nicknames, category words it
  owns — the lexicon]
- **Words the brand avoids:** [banned words, clichés, competitor language, category
  jargon it refuses]
- **How it names things:** [product naming convention, how variants/flavours/shades
  are referred to]

## Signature phrases & taglines
- [Tagline(s) verbatim]
- [Recurring phrases, CTAs, sign-offs the brand actually uses]

## Example copy (real or true-to-voice)
- **Headline:** "[example]"
- **Product line:** "[example]"
- **Caption / UGC hook:** "[example]"
- **CTA:** "[example]"
  (Pull real lines from the site/ads where possible; where you must invent,
  keep them indistinguishable from the brand's own.)

## Do / Don't
- ✅ [a concrete thing to do — "lead with the outcome, not the ingredient"]
- ✅ [...]
- ❌ [a concrete thing to avoid — "never use 'game-changer' or 'elevate'"]
- ❌ [...]
```

---

## Notes

- **Ground it in evidence.** Every rule should trace to something the brand
  actually does in its copy. Quote the hero, the product descriptions, the ad
  captions. If the brand has little copy to draw on, note the gap and build from
  the founder's own words.
- **This is the copy counterpart to the prompt modifier.** The prompt modifier in
  `visual-guidelines.md` constrains the *image*; `brand-voice.md` constrains the
  *words*. Copy-generating skills should read this file the way image skills read
  the prompt modifier.
- Keep examples short and unmistakable. One perfect on-voice headline teaches more
  than a paragraph describing the voice.
